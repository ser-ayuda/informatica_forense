# Catálogo docente Tsurugi
Descomprime y abre index.html. Sube el contenido (no el ZIP) a una subcarpeta como catalogo-tsurugi/ del repositorio.

Para enlazarlo desde el portal, añade en actividades.js:
{ titulo: "Catálogo Tsurugi", descripcion: "Herramientas, funciones y ejemplos", url: "catalogo-tsurugi/index.html", textoBoton: "Abrir catálogo", etiqueta: "Recursos" }
Recuerda la coma entre elementos del array.

Esta entrega es una selección introductoria de 24 herramientas, NO la lista de todos los programas. No garantiza que cada versión concreta las incluya. Comprueba command -v NOMBRE y la ayuda de cada programa. OFFSET e ID son marcadores: sustituir con datos reales obtenidos del caso. Nunca asumir que /dev/sda o /dev/sdb es un dispositivo concreto.

La respuesta anterior incluía herramientas y afirmaciones de instalación sin verificar individualmente; esta selección no debe leerse como certificación de ese listado. Evita ejecutar programas sospechosos y no trabajes sobre evidencia real.

Imágenes: ilustración SVG local original del flujo de laboratorio. No se incluyen capturas de terceros ni imágenes enlazadas remotamente, al no haberse comprobado sus derechos de redistribución. Puedes añadir capturas propias sin datos personales.

El enlace start.me aportado se incluye como recurso externo; no pudo recuperarse su contenido y no se ha utilizado como fuente de las descripciones.

No hay analítica, formularios de datos personales, cookies propias, almacenamiento permanente ni llamadas de red programadas por la aplicación. Los recursos locales se sirven desde el alojamiento; al pulsar enlaces se visitan terceros.

Editar herramientas.js para ampliar el banco; una tarjeta por herramienta. El filtro Todas está disponible. No se ha realizado prueba en navegador; se han validado archivos y enlaces locales del paquete.
